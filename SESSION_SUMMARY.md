# Session Summary — Feature Enrichment/Depletion Plot

## Task Description

Add a visualization to UROPA that compares annotated peak proportions against GTF genomic background to show enrichment and depletion of feature types. Normalize to the length of features in the genome. Parse the reference GTF to predict the background. Triggered with `--summary`.

## Design Questions & Decisions

### 1. Feature granularity
**Q:** Should enrichment be computed at GTF feature-type level (gene/transcript/exon/CDS), biotype level (protein_coding/lncRNA via gene_type attribute), or both?
**A:** Both — configurable, but produce both plots by default.

### 2. Genome denominator
**Q:** How to determine total genome size? (a) Require chrom.sizes file, (b) Infer from GTF max coordinates, (c) Use only annotated genome portion?
**A:** Option (b) — infer from GTF max coordinates by default. Add a `--genome-size` CLI parameter (in Mb) as alternative override.

### 3. Overlapping intervals
**Q:** Should overlapping features of the same type be merged before computing coverage?
**A:** Yes — don't count overlapping regions more than once. Merge intervals per feature type per chromosome.

### 4. Unannotated peaks
**Q:** Include unannotated peaks in denominator or exclude?
**A:** Use total peaks (including unannotated) as denominator.

### 5. Statistical test
**Q:** Which test for significance?
**A:** Binomial test — each peak is an independent trial with expected probability from background proportion. Two-sided to detect both enrichment and depletion. Apply Benjamini-Hochberg FDR correction for multiple testing. Mark significance on plots: `*` p<0.05, `**` p<0.01, `***` p<0.001.

### 6. Multiple queries
**Q:** Per-query enrichment, global enrichment, or both?
**A:** Both — global plots from finalhits plus per-query plots for each named query.

### 7. Output format
**Q:** Add to existing summary PDF, or separate output?
**A:** Separate PNG files for each plot, triggered with `--summary`.

### 8. Biotype background source
**Q:** Use all GTF features or only gene-level features for biotype background?
**A:** Only gene-level features — genes are the natural unit for biotype classification and avoid double-counting from nested features (exons inside transcripts inside genes). Auto-detect biotype attribute: try `gene_type` (GENCODE), then `gene_biotype` (Ensembl), then `biotype`.

### 9. Minimum count threshold
**Q:** Filter feature types with few peaks?
**A:** Show all features in the plot. The binomial test p-values indicate significance.

### 10. Plot library
**Q:** matplotlib or seaborn?
**A:** Seaborn (with matplotlib backend).

### 11. Axis symmetry
**A:** x-axis limits must be symmetric around 0 (same magnitude for + and -) and consistent across all plots in a single run.

### 12. Intermediate data files
**A:** Write a TSV file for each enrichment analysis containing all results (category, observed_count, observed_prop, expected_prop, fold_enrichment, log2_fc, p_value, p_adj, significance). Metadata (total_peaks, genome_size_bp) stored as comment lines. Plots are generated by reading from the TSV files.

### 13. Plot filtering
**A:** Always remove features with 0 observed peaks from plots (but keep in TSV). Optionally filter by minimum background proportion via `--min-background` CLI parameter (in %, default 0 = no filtering).

## Implementation

### New file: `uropa/visualization.py`
Contains all enrichment analysis and plotting code:
- `compute_genomic_background()` — parse GTF, merge intervals, compute coverage per feature type and biotype
- `compute_observed_proportions()` — parse finalhits, count peaks per feature type/biotype/query
- `enrichment_test()` — binomial test + BH correction
- `write_enrichment_tsv()` / `read_enrichment_tsv()` — TSV I/O with metadata
- `plot_enrichment_from_tsv()` — horizontal bar plot from TSV (seaborn)
- `run_enrichment_analysis()` — orchestrator: background -> observed -> test -> TSV -> plot

### Modified: `uropa/uropa.py`
- Added `--genome-size` CLI argument (float, Mb, optional)
- Added `--min-background` CLI argument (float, %, default 0)
- In `--summary` block: calls `run_enrichment_analysis()` before legacy R summary

### Output files per run
- `{prefix}_enrichment_feature_type.tsv` + `.png` — global feature type enrichment
- `{prefix}_enrichment_biotype.tsv` + `.png` — global biotype enrichment
- `{prefix}_enrichment_{query}_feature_type.tsv` + `.png` — per-query feature type
- `{prefix}_enrichment_{query}_biotype.tsv` + `.png` — per-query biotype

### Dependencies added
- `scipy` (binomtest)
- `statsmodels` (multipletests / BH correction)
- `seaborn` (plotting)
- `matplotlib` (backend)
